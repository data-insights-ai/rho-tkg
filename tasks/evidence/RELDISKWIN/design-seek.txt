window instead of walking every entry of the value. Fable design, 13 Nov, frozen for the build.

1. Second ordering: mirror the RAM sidecar's two views (late / recent, index/property_tx_members_window.go:329-332,
   393-423), per row.
   New kinds 7 (rel) / 8 (node). Key: 0x0C | kind | scope | propTok | payload | axis(1B) | t1(8B) | from(8B) | id(8B) |
   txFrom(8B) | version(4B); value: the same 32-B from|allTo|lateTo|last. Tail 37 B for both axes (uniform
   EntityIndexTailLen; the length-check break at badgerstore_entity_index.go:386 and raw terminator logic hold).
   - axis 0x01 (late end order): t1 = orderPreservingInt64Bits(lateTo) (temporal_index_key.go:54). One entry per row
     carrying the value.
   - axis 0x02 (recent order): t1 = ^orderPreservingInt64Bits(last) (descending). Only for widened rows (allTo >
     lateTo): a demoted open row (EndedBy) and a tombstone whose delete wrote ValidTo (AnyPinSpan).
   Read of window [S,E) at pin P:
   a. Seek payload|0x01|enc(S+1), scan while prefix payload|0x01: keep if from < E (and the row meets at P per Meets'
      rule, property_tx_members_disk.go:54-58).
   b. If 0 < P < MaxInt64: seek payload|0x02 start, scan while last > P (break at the first last <= P); keep if from < E
      && allTo > S.
   c. Union by ID; emit (id, min txFrom over the kept rows of id).
   Exactness: per-row judgment = Meets' rule on one row's envelope. The disk member set is a SUBSET of RAM's (RAM unions
   a member's rows into one envelope) and a superset of the resolver's answer; both sound.
   Bound: axis 1 = rows with lateTo > S, +1 boundary; axis 2 = widened rows with last > P, +1. Unrelated PAST history
   is never visited: expected steps ~3 for n = 8/32/128 in the test fixture. Not bounded exactly: (a) many rows
   starting after E (future of the window), (b) an old pin with many widened rows since, (c) open rows with from < E
   (genuine matches). Document these.
   firstTxFrom: min TxFrom over visited rows of the ID; amend store/capabilities.go:398-407 comment ("a lower bound on
   the earliest row that carries the value and may meet the window at txAt"); sound because the windowed door is reached
   only with TxAt (opts.go:92-97, core temporal.go:1192-1197, 1252). If a test shows otherwise, emit 0 (never prune).
