DECISION 1 (D1): ONE FIGURE, 14
Rule: an entity this call read is charged once, at its read (VE:334, :371). An attribution lookup on such an entity is
the same entity examined, not a second candidate: 0. A former-set entry the walk produces that is NOT an entity read is
examined and rejected and has no other owner: 1 candidate, charged as the walk produces it, before the next step (the
shape of ValidEndIndex.TrackUnder: skip what the call's own map already holds, count the rest, refuse at the one that
passes). Public test stays 14; the memory store's count does not change. Remaining store difference, stated in api.md:
badger adds 1 per rejected former entry of another tracked token (memory examines none), 58 against 52 in N2.
Code (attributeFormer, validEndRowsBulk):
 a. `toks := ix.TrackedTokens(); slices.Sort(toks)` (deterministic order; refusal tests need it).
 b. Per token, f := former(tok). Former side when f.n < len(out) && f.n <= hold (hold = 4096): for id in f.each:
    lookups++; if rows, ok := out[id]; ok { append tok } else if err := t.Candidates(1); err != nil { return err }.
    Else entity side: for id, rows in out: lookups++; if f.has(id) { append tok }. No charge (every id is charged).
    A tie (f.n == len(out)) takes the entity side. The pre-walk t.Candidates(walk) at VE:403 is removed.
 c. validEndAttribLookups counts each probe before it is made (both sides).
DECISION 2 (D6): THE PER-CALL WALK IS ACCEPTABLE, THE LOCK IS NOT
Work per call: at most T x E probes (T tracked tokens, E entities this call reads), charged part at most
sum over tokens of min(f, E-1, 4096). No term in store size, none in a former set's size. Accepted under the goal.
Lock: one idxMu.RLock for the pass, released and retaken after at most `hold` probes (Store field
validEndAttribHoldMax, 0 = 4096, tests set it). Former side: retake before the walk when probes so far + f.n > hold,
then fetch f again and choose the side again; never unlock inside a walk of the sidecar map. Entity side: unlock and
retake every `hold` probes, fetch f = former(tok) again after each retake. A pass over empty sets takes the lock once.
Counter validEndAttribHolds (RLock acquisitions). The writer argument is unchanged: a write between holds marks its
entity unknown under a fresh seq, so ResolveUnknownBulkUnder does not install its fold.
TestValidEndFirstCall_CostIgnoresOtherLabels: keep; comment: holds for the listing and the reads, another tracked
label adds at most its rejected former entries (N2).
