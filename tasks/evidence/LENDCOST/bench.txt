LENDCOST bench, 2026-11-04, AMD Ryzen 9 7950X3D, shared with ai-soc's measured run (load in the last column).
BenchmarkLendSorted (badgerstore_lend_cost_bench_test.go): a read-only store of 64 Ki nodes of ~512 B (incompressible),
written in 8 rounds under shrunk levels (layeredOptions(128 KiB, 4)) so its tables span L0..L3; badger's block cache warmed
with every block before the cases; every row out of the entity cache. One op = one call of 4 or 64 IDs; sparse = rows
1,000 apart, dense = adjacent rows. "ids": row j has ID 1+j (adjacent rows, adjacent IDs); "spread": ID 1+j<<22 (adjacent
rows one snowflake millisecond apart). lend = LendNodesSorted; get1txn = Txn.Get + Item.Value + decode per ID in one read
txn; viewperid = the same in a DB.View per ID (v4.102.0's lend path).
before = the red commit's lend (one iterator, stepTo or Seek per miss); after = the fix (lendAfterMiss).
Binaries built once each (go test -c), run alternately, 3 rounds:
  GOMAXPROCS=2 <bin> -test.run '^$' -test.bench BenchmarkLendSorted -test.cpu 1 -test.benchtime 1000x -test.count 1
(scratch script bench.sh; ranges = min-max of the 3 rounds; B/op and allocs = mean.)
