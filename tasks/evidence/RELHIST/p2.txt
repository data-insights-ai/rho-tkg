3. What was built
- (i) effective_timelines.go: after the no-history shortcut, a plain read (rd.snap == nil, !rd.scan, a current row)
  asks nodeHeadTimelines / relHeadTimelines (effective_head.go): headValid at the LOWEST pin (every pin >= maxTx), a
  whole entry, each winner read once (lent), rowAtTx per pin, one headHits per call. Otherwise effectiveTimelinesOver
  folds every pin and hands the fold at the HIGHEST pin with its facts to noteNodeHead / noteRelHead (skeleton path and
  whole-history path alike; the facts qualify only when every row is recorded by that pin, as for the singular door).
- (ii) headSupersede (effective_head.go) = headOverlay of the new current row n, plus the old current row's TxTo:
  - monotonic arm (out.cascade false): TxTo is not read by the positional tiling; headOverlay's tiling check stands.
  - own-bounds arm (kept, or switched by armSwitches): n replaces the old current row (TxTo == n.TxFrom > its TxFrom)
    and so caps every row starting at or before n at n's start (supersessionCaps: any newer replacing row). n open:
    the paint covers [start, open) already. n bounded: after its end every row starting at or before n is gone; with
    no bound of the entry after n's start no row starts later, so those instants are a gap (pieces from n's end on
    dropped); otherwise the entry is dropped.
  - maxTxTo raised to the supersession instant (the fold's maxTxTo).
  Called from updateNodePreparedInternal / updateRelationshipPreparedInternal (both store branches),
  closeNodeVersionInternal / closeRelVersionInternal, replaceNodeVersionInternal, with the entry read before the
  current row is mutated (nodeHeadBeforeWrite). No valid entry before the write: nothing is touched (stale by the token
  as before). Refused: the entry is dropped (as a correction's refusal).
- Not covered, by design: CloseVersion or a bounded Update of a MONOTONIC chain (same start, earlier end makes the
  chain non-monotonic; armSwitches needs every row bounded) drops the entry; property CAS, UpdateInPlace (no history
  write), batch/ingest doors that do not reach these internals: unchanged (stale by the token).
- Oracle coverage (one run, 2 seeds x 60 steps x memory/badger/tiered): 219 overlays, 741 head hits; supersede kept in
  the monotonic arm 15x, own-bounds arm 114x, of which the bounded gap rule 21x (counted with a temporary print).
