- Red test first (lesson 78): the row names the test and its break-the-code cases before the first build command; RED output kept.
- Tests (lesson 87): v4 `go test -short` of the touched packages (seconds); v5 `cd v5 && GOWORK=off GOTOOLCHAIN=local go test -short -count=1 ./<owned packages>` with Go 1.26.9 (`~/go/pkg/mod/golang.org/toolchain@v0.0.1-go1.26.9.linux-amd64/bin/go`; the host's `/usr/local/go` is 1.26.6), private `GOCACHE` per WP under the scratchpad. Long tests only in the release gate (`make ci-docker`, incl. `make test-race`). Build briefs end with `make lint-docker security-docker`.
- One branch + one worktree per WP under the scratchpad (`S/wp-NN-wt`, branch `wp-NN-<name>` off `v5-takeover`, or off `main` for v4); files owned by a WP are disjoint from every other WP in the same wave; a needed change outside the owned set is reported, not made. Agents never tag or push: the main session merges, removes the worktree, tags and pushes (lesson 79 (9)); `origin/v5` is never pushed by us; v5 tags need René's OK (gate table).
- Never work around a denied command: report it. Agents report (text to the main session); only this file plans (lesson 84).
- Every job > 2 min: ETA at start, `status.txt` (done/total/ETA) next to the outputs.
